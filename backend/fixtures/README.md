# Fixtures: the demo estate

Everything here is generated by `scripts/generate_fixtures.py` (seed `20261101`, as of `2026-11-01T00:00:00Z`)
except the two price snapshots, which are captured from the providers' public price lists. Regenerate with:

```sh
uv run python scripts/snapshot_aws_prices.py     # official AWS Price List Bulk API (streams ~300 MB once)
uv run python scripts/snapshot_azure_prices.py   # Azure Retail Prices API (public, no credentials)
uv run python scripts/generate_fixtures.py       # the estate, priced with the snapshots above
```

`manifest.json` records the SHA-256 of every source file; the ingestion pipeline records it per snapshot, so a
changed fixture is always visible.

## Sources, in each provider's native shape

| Source | Files | Shape |
|---|---|---|
| AWS inventory (2 accounts) | `sources/aws/<account>/ec2_describe_instances.page{1,2}.json`, `ec2_describe_volumes.page{1,2}.json`, `ec2_describe_addresses.json` | boto3 `DescribeInstances` / `DescribeVolumes` / `DescribeAddresses` responses, paginated with `NextToken` |
| AWS metrics | `sources/aws/<account>/cloudwatch_get_metric_data.{request,response}.json` | `GetMetricData`, daily `Average` and `Maximum` of `AWS/EC2 CPUUtilization`, timestamps descending (CloudWatch's default) |
| Azure inventory (2 subscriptions) | `sources/azure/resource_graph.{virtual_machines,disks,public_ip_addresses}.json` | Azure Resource Graph rows (ARM resource with `properties`) |
| Azure metrics | `sources/azure/monitor.percentage_cpu.json` | Azure Monitor metrics responses, `Percentage CPU`, `P1D`; days without data carry only `timeStamp` |
| Billing | `sources/billing/focus_{aws,azure}_2026-10.csv` | FOCUS 1.4 cost-and-usage columns, one export per provider, daily charge periods |
| AWS prices | `pricing/aws_price_list_snapshot.json` | rows from the official `AmazonEC2` and `AmazonVPC` us-east-1 offer files, with offer version, publication date and SHA-256 |
| Azure prices | `pricing/azure_retail_prices_snapshot.json` | real `Items` from `prices.azure.com/api/retail/prices` (`api-version=2023-01-01-preview`), with the exact filter used |

## Planted data defects (ingestion must catch every one)

| Defect | Where | Expected handling |
|---|---|---|
| Invalid timestamp | AWS instance `i-0bad0c0ffee000001`, `LaunchTime: "not-a-date"` | quarantined with the reason |
| Missing required field | Azure VM `vm-dev-half-provisioned` has no `hardwareProfile.vmSize` | quarantined |
| Duplicate across pages | one AWS volume appears on both `DescribeVolumes` pages | deduplicated, counted |
| Non-numeric cost | one AWS FOCUS row, `BilledCost: n/a` | quarantined |
| Lowercase currency | one AWS FOCUS row, `BillingCurrency: usd` | normalized to `USD`, counted as a warning |
| Timestamp without offset | one AWS FOCUS row, `ChargePeriodStart` without `T`/`Z` | normalized to UTC ISO 8601, counted as a warning |
| Exact duplicate row | one AWS FOCUS line repeated | deduplicated, counted |
| Mixed tag keys | `env`, `Environment`, `environment`; values `dev`, `Dev`, `development`, `Production` | normalized to one key and value set |
| Resource-id case | Azure FOCUS `ResourceId` is lowercased; inventory ids keep their case | reconciled case-insensitively |

Monthly estimates use the FinOps convention of 730 hours per month. The October billing export has 744 hours,
so actual October cost and the monthly estimate differ by design; the data tests check both.
